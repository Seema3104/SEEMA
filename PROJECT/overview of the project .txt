Project Conclusion:STAR Approach for Pizza Sales Data Analysis Project

Situation: I worked on a Pizza Sales Data Analysis project to understand a pizza restaurant's sales performance. The business had transactional sales data, but it needed meaningful insights into revenue, customer ordering patterns, and product performance.

Task: My objective was to analyze the sales data using SQL and develop an interactive Power BI dashboard to track key performance indicators, identify sales trends, and evaluate the performance of different pizza categories and products.

Action: I imported the data into SQL Server and wrote queries using JOINs, GROUP BY, aggregate functions, and subqueries. I calculated total revenue, total orders, total pizzas sold, average order value, and average pizzas per order. I also analyzed daily, monthly, and hourly order trends, sales by pizza category and size, and the top five and bottom five pizzas. Then I created an interactive Power BI dashboard with KPI cards, charts, and slicers. I also validated the dashboard calculations against the SQL results.

Result: I developed an interactive dashboard that provided a clear overview of sales performance and helped identify popular pizza categories, preferred sizes, peak ordering periods, and underperforming products. The project strengthened my SQL querying, data visualization, analytical thinking, and business intelligence skills. It also demonstrated how data analysis can support better decisions about inventory, staffing, and marketing.
